# \--------------------------------------------------------------

# KAIP ŽAISTI

# \--------------------------------------------------------------

# Įrankių juosta (toolbar)

# &#x20; Apačioje esanti 9 langelių juosta yra tavo greitoji prieiga.

# &#x20; Daiktus į ją priskiri tempdamas juos iš inventoriaus.

# &#x20; Langelį pasirenki klavišais 1–9; pasirinktas langelis

# &#x20; pažymimas. Veiksmai (statymas, valgymas, įrankio naudojimas)

# &#x20; taikomi TIK pasirinktam juostos langeliui — ne visam

# &#x20; inventoriui.

# 

# &#x20; - Pasirinkus įrankį ar ginklą, jis automatiškai paimamas

# &#x20;   į rankas. Perjungus į bloką ar maistą, įrankis padedamas.

# &#x20; - Jei pasirinktas langelis tuščias, dešinysis pelės

# &#x20;   mygtukas nieko nedaro.

# 

# Kasimas ir įrankiai

# &#x20; Blokus daužai kairiuoju pelės mygtuku. Tinkamas įrankis

# &#x20; kasa greičiau: kirtiklis — akmenį ir rūdas, kirvis — medį,

# &#x20; kastuvas — žolę ir žemę. Sudaužyti blokai dažniausiai

# &#x20; iškrenta kaip daiktai ir patenka į inventorių.

# 

# Gamyba (crafting)

# &#x20; Gamybos receptai inventoriuje atsiranda automatiškai, kai

# &#x20; surenki reikiamas medžiagas. Surinkęs pakankamai išteklių,

# &#x20; gali pasigaminti akmeninius ir geležinius įrankius

# &#x20; (kirtiklį, kastuvą, kirvį), kalaviją bei skrynią.

# 

# Skrynios

# &#x20; Skrynią pastatai kaip bloką ir atidarai dešiniuoju pelės

# &#x20; mygtuku. Joje gali laikyti daiktus tempdamas juos tarp

# &#x20; inventoriaus ir skrynios.

# 

# Būklė

# &#x20; Alkis ir troškulys laikui bėgant mažėja. Kai bent vienas

# &#x20; nukrenta iki nulio, pradeda sektis sveikata. Valgyk ir gerk,

# &#x20; kad išliktum gyvas. Stebėk ir ištvermės juostą.

# 

# Radiacija

# &#x20; Tam tikrose miško vietose tyko radiacija, kuri pamažu

# &#x20; sekina sveikatą. Venk jos arba ruoškis iš anksto.
